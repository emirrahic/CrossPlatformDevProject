# GymLog

GymLog is a mobile workout log where gym-goers record each exercise they do, including sets, reps and weight. Users can add a progress photo and review their workout history to see how they improve over time.

## Run the project

```
npm install
npx expo start
```

## Features

- [x] List of workouts (mock data)
- [ ] Workout details screen
- [ ] Add and edit workouts
- [ ] Login with Supabase
- [ ] Progress photo from camera or gallery
- [ ] Dark mode and kg/lb settings
